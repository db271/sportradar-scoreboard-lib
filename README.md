# Live Football World Cup Scoreboard

A small Java library that keeps track of live football matches and their scores. It's a
solution to the Sportradar *Data & Odds Platform* coding exercise.

> **Status:** work in progress. Pull requests add the implementation step by step; the plan
> is in [`design/DESIGN.md`](design/DESIGN.md#7-delivery-plan-pull-requests).

## Requirements

- Java 21 or newer
- Maven 3.8 or newer

## Build and test

```bash
mvn verify
```
